🚀 HOW TO ADD ENVIRONMENT VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open file:
   server/.env

2. Add your variable:
   KEY_NAME=your_value_here

3. Save file

4. Restart server:
   npm start

5. Access in code:
   process.env.KEY_NAME
