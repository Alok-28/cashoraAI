STEP 1: GET YOUR PERSONAL ACCESS TOKEN (1 minute)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open in browser:
   https://github.com/settings/tokens

2. Click:
   → "Generate new token"
   → "Generate new token (classic)"

3. Fill in:
   Note: CashoraAI
   Expiration: 30 days
   Scopes: Check only "repo"

4. Click "Generate token"

5. COPY THE TOKEN (starts with ghp_)
   ⚠️  Save it! You can only see it once

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: RUN THE PUSH COMMAND (1 minute)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open PowerShell and run this command:

git push https://[YOUR_TOKEN]@github.com/Alok-28/cashoraAI.git main

Replace [YOUR_TOKEN] with your actual token from Step 1.

EXAMPLE:
git push https://ghp_abc123xyz789@github.com/Alok-28/cashoraAI.git main
