HOW TO PUSH TO GITHUB
================================================================================

OPTION 1: Using GitHub CLI (Easiest)
  $ gh auth login
  $ git push origin main

OPTION 2: Using Personal Access Token
  1. Create token at: https://github.com/settings/tokens
  2. Run: git push https://<token>@github.com/Alok-28/cashoraAI.git main

OPTION 3: Using SSH (Most Secure)
  1. Add SSH key to GitHub: https://github.com/settings/ssh/new
  2. Run: git remote set-url origin git@github.com:Alok-28/cashoraAI.git
  3. Run: git push -u origin main
